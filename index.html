Endpoints

  • /models-arena.json — flat lookup keyed by Arena model name (one entry per leaderboard model).
  • /models.json — full models.dev catalog with arena field attached where matched (87 of 364 entries on last sync).
  • /models.json.rub.json — same catalog with pricing_rub field added (USD→RUB per token via ЦБ РФ daily rate).
  • /_meta.json — last-sync timestamp, source URLs, counts, currency metadata.
  • /currency.json — current FX rates (ЦБ РФ primary, daily).
  • /INTELLIGENCE.md — formula, confidence buckets, matching strategy.
  • /sync-arena — the Bun script that builds it all (packages/core/script/sync-arena.ts).

Currency display

Append ?currency=rub to any URL below to load the RUB-priced variant (e.g. models.json?currency=rub is equivalent to models.json.rub.json). The current Bank of Russia rate is fetched once per day and written to currency.json by packages/core/script/sync-currency.ts.
